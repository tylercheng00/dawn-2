# DAWN-2 Concept Launch Vehicle · 曙光二號概念火箭

**Live interactive 3D model · 互動 3D 模型：** https://tylercheng00.github.io/dawn-2/

---

DAWN-2 is a personal aerospace project using a reusable orbital launch vehicle as a case study to work through the full engineering logic of a rocket, from design and materials to manufacturing and recovery. Built on publicly available aerospace engineering knowledge with AI-assisted design tools. Concept and digital-prototype stage; no physical hardware or testing. No patents filed.

曙光二號是我的個人航天項目，以可重複使用的入軌運載火箭為例，系統理解運載火箭從設計、選材、製造到回收的完整工程邏輯。參考公開航天工程知識，借助 AI 輔助設計工具完成。目前處於概念設計與數字原型階段，沒有實體硬件或試驗，沒有申請專利。

## What's on the page · 頁面內容

- **Interactive 3D model** — rotate, zoom, cutaway and exploded views; click any part to see its material, manufacturing process and function.<br>
  **互動 3D 模型**：可旋轉、縮放、剖面及分解檢視；點擊任何部件即可查看其材料、製造工序及功能。
- **Engineering overview** — work breakdown structure, build sequence, materials rationale and key engineering challenges.<br>
  **工程概覽**：工作分解結構、製造流程、選材理據及主要工程難點。

The content is kept at concept / overview level. Detailed propulsion, guidance and performance parameters are intentionally not included.

內容只保留在概念及概覽層面，刻意不包含詳細的推進、制導及性能參數。

## Status · 狀態

Concept design and digital prototype — no physical hardware or testing.

概念設計及數字原型，沒有實體硬件或試驗。

## Technical notes · 技術說明

- A single self-contained `index.html` (fonts and [three.js](https://threejs.org/) r128, MIT License, are inlined), served by GitHub Pages with no build step.<br>
  單一自足的 `index.html`（字型及 three.js r128［MIT 授權］已內嵌），由 GitHub Pages 直接提供，無需建置。
- Works on desktop and mobile browsers with WebGL.<br>
  支援具備 WebGL 的桌面及手機瀏覽器。
